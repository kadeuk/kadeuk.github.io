# ☁️ 내 컴퓨터가 구름 위에 있다? (VDI 솔루션 비교)

재택근무가 일상이 되면서, 회사 PC를 집에 들고 가는 대신 **"인터넷으로 접속하는 가상 PC"**를 쓰는 회사가 늘고 있습니다.
Microsoft에는 두 가지 비슷한 서비스가 있는데, 이 둘을 구분하는 것이 M365 관리자의 핵심 역량입니다.

---

## 1. Windows 365 (Cloud PC)
**"SaaS: 넷플릭스처럼 구독하는 나만의 PC"**

* **정의:** 사용자가 신경 쓸 것 없이, MS가 알아서 만들고 관리해 주는 **완전 관리형 서비스**.
* **특징:**
    * **1인 1PC:** 사용자 한 명에게 전용 PC 한 대가 할당됨. (Dedicated)
    * **고정 요금제:** 사양이 정해져 있고, 많이 쓰든 적게 쓰든 월 요금이 똑같음. (예: 월 4만 원)
    * **쉬운 관리:** Intune(엔드포인트 관리자)에서 일반 PC처럼 똑같이 관리 가능.
    * **비유:** **"풀옵션 오피스텔 월세"** (관리비 포함, 몸만 들어가면 됨).

---

## 2. Azure Virtual Desktop (AVD)
**"PaaS: 내 입맛대로 뜯어고치는 커스텀 PC"**

* **정의:** Azure 클라우드 위에 관리자가 직접 서버를 세팅하고 최적화하는 **유연한 서비스**.
* **특징:**
    * **멀티 세션 (Multi-session):** [★ 시험 빈출] **Windows 10/11 하나에 여러 명의 직원이 동시에 접속**해서 쓸 수 있음. (자원 절약)
    * **종량제 요금:** 쓴 만큼만 냄. (주말에 PC 꺼두면 요금 안 나감).
    * **복잡한 관리:** Azure 포털에서 네트워크, 스토리지 등을 직접 세팅해야 함.
    * **비유:** **"직접 지은 전원주택"** (내 맘대로 설계 가능하지만, 보일러 고장 나면 내가 고쳐야 함).

---

## 3. 한눈에 보는 비교표 (시험 완벽 대비)

| 구분 | **Windows 365 (Cloud PC)** | **Azure Virtual Desktop (AVD)** |
| :--- | :--- | :--- |
| **핵심 컨셉** | **단순함 (Simplicity)** | **유연함 (Flexibility)** |
| **사용자** | 1인 1PC (Dedicated) | **다중 사용자 (Multi-session)** 가능 |
| **요금 방식** | **고정 월정액** (예측 가능) | **종량제** (쓴 만큼, Azure 소비 기반) |
| **관리 도구** | Microsoft Intune | Azure Portal + Intune |
| **데이터 저장** | 사용자 프로필이 PC에 저장됨 | **FSLogix** 기술로 프로필 따로 저장 [★] |
| **추천 대상** | IT 인력이 부족하고, 예측 가능한 비용을 원하는 중소/중견 기업 | IT 전문 인력이 있고, 비용 최적화가 중요한 대기업 |

---

## 4. 왜 Windows 11인가?
두 서비스 모두 최신 **Windows 11**을 완벽하게 지원합니다.
* **보안:** TPM 2.0 같은 최신 보안 기술이 가상 PC에도 적용됨.
* **협업:** Teams 화상 회의가 끊기지 않도록 최적화되어 있음.
* **Copilot:** 윈도우용 AI 비서(Copilot)를 가상 PC에서도 사용 가능.
