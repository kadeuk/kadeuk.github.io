## 1. Office 365 (O365)
- **정의:** 클라우드 기반의 **생산성 앱 및 서비스** 모음.
- **포함 내용:** Word, Excel, PowerPoint, Outlook, Exchange(이메일 서버), SharePoint.
- **핵심:** 여기에 'Windows 운영체제'나 '강력한 보안 관리(Intune)'는 포함되지 않음.

## 2. Microsoft 365 (M365) - *가장 중요*
- **공식:** **M365 = Office 365 + Windows Enterprise + EMS (보안/관리)**
- **특징:**
    - 운영체제(Windows)와 앱(Office), 그리고 관리 도구(EMS)를 한 번에 구독하는 형태.
    - 기업 보안을 위해서는 O365가 아니라 **M365**를 써야 함.

## 3. Windows 365 (Cloud PC)
- **정의:** 클라우드에서 실행되는 전체 Windows PC를 사용자 기기로 **스트리밍**하는 서비스.
- **특징:**
    - 내 PC 사양과 상관없이 언제 어디서나 똑같은 윈도우 환경에 접속 가능.
    - 데이터가 내 PC가 아니라 마이크로소프트 서버에 저장되므로 보안에 강력함.
    - **시험 키워드:** "Cloud PC", "스트리밍", "하이브리드 업무 환경"

## 4. 요약
- 앱만 필요하다? -> **Office 365**
- 앱 + 윈도우 + 보안 관리가 다 필요하다? -> **Microsoft 365** (기업 표준)
- 컴퓨터 자체가 필요하다(가상)? -> **Windows 365**
